# Historical README and Development Notes

This folder preserves three README-style documents from earlier stages of the EV-Charging-M1-M2 project. They are kept for traceability, not as current setup instructions.

## Files

- `README_CASE_STUDY_SCREENING.md` — earlier chainage-proxy screening MILP stage.
- `README_DIRECTED_DISTANCE_INTEGRATION.txt` — intermediate directed OSM distance integration note.
- `README_INTERSTATION_GAP.md` — development note for the interstation-spacing constraints.

## Which document is authoritative?

Use the repository-root `README.md` for the current project overview, final directed-network scenario results, validated demand scope, assumptions, and current run/test instructions. Use `results/final_case_study_screening_directed/` for the preserved final scenario inputs and outputs.

The archived notes intentionally retain their original technical content, with a warning at the top. Historical commands, paths, placeholders, and statements about data readiness may have been superseded. Do not apply old patch instructions without checking the current `main` branch.
