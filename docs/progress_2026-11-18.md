# Development progress — 18 November 2026

## Implemented in this repository

- EV fast-charging MILP baseline solved through SciPy/HiGHS.
- Two-phase Revised Simplex implementation for continuous LPs, with Phase I artificial-variable feasibility search and Phase II optimization.
- EV LP-relaxation builder connected to the in-house Revised Simplex implementation.
- Mixed-integer Gomory (GMI) cuts for designated integer variables, followed by Dual Simplex re-optimization.
- Synthetic EV example: custom GMI + Dual Simplex reached the same objective (21,000 illustrative cost units) as the HiGHS MILP result after three cuts. This is only a software test.
- Seeded small-instance benchmark: 100 generated MILPs compared with HiGHS; all feasible-instance objectives matched, infeasibility decisions agreed where applicable, 57 GMI cuts in total, and at most three cuts in one instance.
- Convex quadratic extension of the continuous LP relaxation for the proposal's simplified power-loss penalty, with approximate KKT residual checks.
- M/M/s (Erlang-C) queueing scenario calculator.
- CSV/JSON input validation, explicit AADT-to-demand scenario estimator, templates, optional OSM geometry/graph tools, and road-network distance-matrix generation.
- Reference context: an EVUP directory snapshot with 12 public charging locations, historic ADB traffic counts, a record of 2025 counter-network reporting, and electrical-data limitations.
- Automated tests: 16 passed in the development environment on 18 November 2026.

## Not yet complete or not empirically verified

- Current numerical traffic counts and chainages from the Road Department's M1/M2 counters. Public reporting confirms that counters are present but does not publish the numeric station-level series.
- Site-specific ENA available grid capacity, transformer loading, voltage, and connection-cost data. Nationwide ENA aggregates and old schematic point maps cannot replace these values.
- Geocoded candidate-site and demand-point coordinates, manually checked M1/M2 road alignment, and verified road-distance matrix. OSM download scripts exist, but the road graph has not yet been downloaded and inspected in this development environment.
- Calibrated demand, fixed/variable costs, distance/power weights, line-loss engineering inputs, and station arrival/service distributions.
- Larger-scale tests and a full Armenian case-study run. The custom solver is research/educational code and is not yet shown to scale to the national network.

## Reproduction

From the repository root:

```powershell
python -m pytest -q
python scripts\benchmark_gomory_random.py
python scripts\run_ev_gomory.py
python scripts\run_quadratic_extension.py
python scripts\run_queueing_demo.py
```

The generated examples are synthetic or explicitly scenario-based. Do not report their objective values, resistance, queue metrics, or demand values as measured Armenia case-study results.
