Important interpretation
These are optimized candidate-site locations, not approved or operating public charging stations. Site access, land availability, grid connection, and local costs remain unverified. Demand represents three documented scopes only, not all traffic on M1/M2.
Selected-site coordinates and charger allocations are embedded from the repository's final scenario CSV files. Demand-reference coordinates are from the project's traffic-location records. The basemap is provided by OpenStreetMap; internet access is required. Open this map with Open_Map.bat so the browser sends the HTTP Referer required by the OSM tile service.
